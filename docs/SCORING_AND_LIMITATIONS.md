# 数学评分、奖励与此次已知问题

## 正确性与格式

固定v4先提取明确最终答案，再用Math-Verify判断等价。明确错误为0；正确为1；正确且原始输出格式与EOS合格加0.1。格式奖励不能奖励错误答案。
测试只使用固定v4，不走API；格式单独统计。无法提取/解析/核验的回答记为未通过并保留分母，这不等于已证明数学错误。

## 训练时API边界

只有Math-Verify无法确认时才进入可选API。DeepSeek识别response中的一个连续原文答案片段，不能做题、判对错、修正值、化简、补全或拼接；提取后仍由本地Math-Verify判分。原格式判断不会因API恢复而补发格式奖励。
每题4答，任一回答异常结束或仍无法确认时屏蔽本题G4；不会屏蔽同一个生成批次的其他题。屏蔽组也可能有其他正确回答，不能称作四答全错。

## 此次训练信号

549题中243组有真实数学对错差异、170组只有正确答案之间的格式奖励差异、68组有效但奖励全同、68组被屏蔽。非零优势共413组；仅格式信号占41.16%。前/中/后三段非零优势137/138/138，不能说优势整体耗尽。数学对错组90/79/74呈下降，但各段题目不同，不能把它当固定测试学习曲线。

## 已诊断而未覆盖历史的缺陷

- 51道正常结束但被屏蔽的题共有204答，150答明确、54答未确认。35答已有API提取内容，其中自然语言过长、损坏数学表示和文字结论等仍未被Math-Verify解析；19答是null或不符合逐字摘取约束。
- 其中5份空回答原应为作答失败；API兜底将其升级为未确认，null后没有恢复，造成G4屏蔽。历史源码保留这一行为，后续生产训练应修复并增加回归后重新验证。
- 人工安全摘取或披露规范化后，31份答案离线复核21对10错，可使28题完整可判。这是事后诊断，没有回填此次训练奖励，也没有改官方测试成绩。
- Base统一复评中1份AttributeError记为未通过；未记录TimeoutError。历史复评平台与本轮原评分平台不同，固定的是源码和合同依赖，不声称完整环境逐项一致。

最终答案正确不保证推导过程正确；训练中统计正确数也不能代替独立测试集成绩。没有多随机种子或同数据同预算的一次/多次训练对照，不能据此断言多阶段训练本身导致所有提升。
